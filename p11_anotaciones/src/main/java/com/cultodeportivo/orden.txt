ORDEN - P11_ANOTACIONES
===========================================

¿Qué es una anotación?
   Metadato adjunto a código (clase, método, campo, parámetro).
   No cambia la lógica directamente; la usa el compilador, la JVM o herramientas externas.
   Sintaxis:  @NombreAnotacion          → sin atributos (marker)
              @NombreAnotacion(k = v)   → con atributos

─────────────────────────────────────────

1. anotaciones/EjemploAnotacionesJDK.java   ← Anotaciones del JDK
   - @Override          → compilador verifica sobreescritura real; evita errores de typo
   - @Deprecated        → marca como obsoleto; genera warning al usar
     desde Java 9: @Deprecated(since="x", forRemoval=true)
   - @SuppressWarnings  → silencia warnings: "unchecked", "deprecation", "rawtypes"...
   - @FunctionalInterface → verifica 1 solo método abstracto en la interfaz

2. anotaciones/Init.java                    ← Anotación propia: marker en métodos
   Meta-anotaciones (anotaciones sobre anotaciones):
   - @Retention(RetentionPolicy.RUNTIME)  → visible en runtime con Reflection
     SOURCE  → solo en código fuente (descartada por compilador)
     CLASS   → en bytecode, no en runtime  (default)
     RUNTIME → en bytecode y en runtime ← necesario para Reflection
   - @Target(ElementType.METHOD)          → solo aplicable a métodos
     FIELD, METHOD, TYPE, PARAMETER, CONSTRUCTOR, LOCAL_VARIABLE...

3. anotaciones/JsonAtributo.java            ← Anotación propia: con atributos en campos
   - @Documented   → aparece en Javadoc generado
   - @Target(FIELD)
   - @Retention(RUNTIME)
   Atributos:  String nombre() default ""       → clave JSON
               boolean capitalizar() default false → aplicar TitleCase

4. modelo/Estudiante.java                   ← Clase con las anotaciones aplicadas
   - @JsonAtributo()            → campo incluido, clave = nombre del campo
   - @JsonAtributo(nombre="x")  → clave personalizada
   - @JsonAtributo(capitalizar=true) → aplica TitleCase al serializar
   - @Init                      → método privado de normalización
   - Campos SIN @JsonAtributo   → ignorados por el serializador

5. procesador/AnotacionException.java       ← RuntimeException del procesador

6. procesador/JsonSerializador.java         ← API de Reflection
   Reflection: inspeccionar y operar sobre clases en runtime.
   Métodos clave:
   - objeto.getClass().getDeclaredMethods()    → todos los métodos (incluye private)
   - objeto.getClass().getDeclaredFields()     → todos los campos  (incluye private)
   - metodo.isAnnotationPresent(Clase.class)   → ¿tiene esta anotación?
   - campo.getAnnotation(Clase.class)          → obtener la instancia de la anotación
   - campo.setAccessible(true)                 → permitir acceso a private
   - campo.get(objeto)                         → leer valor del campo
   - campo.set(objeto, valor)                  → escribir valor del campo
   - metodo.invoke(objeto)                     → invocar el método

7. anotaciones/EjemploAnotacion.java        ← main: demo completa
   Flujo: Estudiante → inicializarObjeto (@Init) → convertirJson (@JsonAtributo) → String JSON

===========================================
EXTRA:
   - @Inherited   → la anotación en superclase se hereda por subclases
   - @Repeatable  → permite aplicar la misma anotación varias veces al mismo elemento
   - Frameworks populares que usan anotaciones con Reflection:
     Spring → @Autowired, @Component, @RestController
     JPA    → @Entity, @Column, @Id
     JUnit  → @Test, @BeforeEach, @AfterAll
     Jackson→ @JsonProperty, @JsonIgnore  (exactamente lo que implementamos)
